## Requirements

- Java 17
- Maven 3.8 or later
- IDE (optional, e.g., IntelliJ IDEA, Eclipse)

## Installation and Build the Project

1. **Clone the Repository**:

   git clone https://github.com/thanigaiveldinesh/backend-sap-serviceagent.git
   
   cd service-agent-backend
   
2. **Build the project**:
   
    mvn clean package

3. **Run the Backend**:

   Navigate to the target folder

   java -jar target/service-agent-backend-1.0-SNAPSHOT.jar

   Backend should be started with localhost:80 port.

   
## Testing

To run the unit tests, use:

**mvn test**

The application includes unit tests that verify the functionality of the CO2 calculation logic.
